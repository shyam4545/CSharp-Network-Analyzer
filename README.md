# C# Network Traffic Analyzer

A simple network traffic analysis tool built in C# with Windows Forms. This application allows users to select a network interface and view captured packets in real-time.

## How to Run

1.  Ensure you have **.NET Framework 4.5.2** (or later) installed.
2.  Install the **Npcap** packet capture driver from the [official website](https://npcap.com/#download).
3.  Clone or download this repository.
4.  Open the solution file (`.sln`) in Visual Studio.
5.  Run the project (preferably as an administrator).
